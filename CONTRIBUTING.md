# Contributing to P2Pear

First off, thank you for considering contributing to P2Pear! It's people like you that make open source such a fantastic community to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.
*   Use the provided Bug Report Issue Template.
*   Provide clear and detailed steps to reproduce the issue.
*   Include screenshots if it's a UI issue.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion, including completely new features and minor improvements to existing functionality.
*   Use the provided Feature Request Issue Template.
*   Provide a compelling reason why this feature should be implemented.

### Pull Requests
The process described here has several goals:
*   Maintain project quality.
*   Fix problems that are important to users.
*   Engage the community in working toward the best possible P2Pear.

Please follow these steps:
1.  **Fork the repository** and create your branch from `main`.
    *   Use descriptive branch names: `feature/your-feature-name` or `fix/your-fix-name`.
2.  **Install dependencies** using `pnpm install`.
3.  **Make your changes**. Ensure your code adheres to the existing style.
4.  **Run the linter** using `pnpm run lint` and fix any issues.
5.  **Test your changes** thoroughly. (Especially WebRTC connection flows).
6.  **Commit your changes** using [Conventional Commits](https://www.conventionalcommits.org/).
    *   Examples: `feat: add file preview support`, `fix: resolve safari connection issue`.
7.  **Push to your fork** and submit a Pull Request using our template.
